# Notion Homes

Luxury Egyptian Properties for UK Clients

## About

Notion Homes is a premier UK-based property company specializing in luxury vacation homes and investment properties in Egypt's most sought-after destinations including Hurghada, El Gouna, North Coast, and Cairo.

## Features

- Property browsing with advanced filtering
- Property details with image galleries
- Contact and inquiry forms
- Responsive design for all devices
- WhatsApp integration for instant communication

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Sanity CMS
- Framer Motion

## Deployment

This website is built with Next.js and can be deployed to Vercel, Netlify, or any other hosting platform that supports Next.js applications.
